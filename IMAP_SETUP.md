# Подключение почтовых ящиков по IMAP

## 1. Подготовка проекта

Установите зависимости и примените миграции:

```powershell
.\venv\Scripts\python.exe -m pip install -r requirements.txt
.\venv\Scripts\python.exe manage.py migrate
```

Для production задайте постоянный ключ шифрования. После подключения ящиков его нельзя менять — иначе сохранённые пароли перестанут расшифровываться.

```powershell
$env:MAILBOX_ENCRYPTION_KEY="СЮДА_КЛЮЧ_FERNET"
```

Сгенерировать ключ один раз:

```powershell
.\venv\Scripts\python.exe -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"
```

На локальной машине без переменной ключ детерминированно создаётся из `SECRET_KEY` Django.

## 2. Яндекс

1. Откройте Яндекс ID → **Безопасность**.
2. В разделе **Доступ к вашим данным** выберите **Пароли приложений**.
3. Создайте пароль для почтового клиента, например `SMTP_SL`.
4. Скопируйте пароль: повторно Яндекс его не покажет. По справке Яндекса новый пароль может начать работать не сразу.
5. В SMTP_SL откройте **Ящики → Добавить ящик**.
6. Выберите провайдера **Яндекс**, введите полный email и пароль приложения.

Параметры подставляются автоматически:

- IMAP: `imap.yandex.ru`, порт `993`, SSL;
- SMTP: `smtp.yandex.ru`, порт `465`, SSL;
- логин: полный адрес почты.

Официальная справка: <https://yandex.ru/support/id/ru/authorization/app-passwords>

## 3. Mail.ru

1. В Mail.ru откройте **Настройки → Все настройки → Безопасность**.
2. Выберите **Пароли для внешних приложений**.
3. Создайте отдельный пароль с названием `SMTP_SL` и скопируйте его.
4. В SMTP_SL откройте **Ящики → Добавить ящик**.
5. Выберите провайдера **Mail.ru**, введите полный email и пароль внешнего приложения.

Параметры подставляются автоматически:

- IMAP: `imap.mail.ru`, порт `993`, SSL;
- SMTP: `smtp.mail.ru`, порт `465`, SSL;
- логин: полный адрес почты.

Официальная справка: <https://help.mail.ru/mail/faq/password/external/>

## 4. Gmail

1. Включите двухэтапную аутентификацию Google: <https://myaccount.google.com/security>.
2. Откройте страницу паролей приложений: <https://myaccount.google.com/apppasswords>.
3. Создайте новый пароль приложения для `SMTP_SL` и скопируйте 16-значный код.
4. В SMTP_SL выберите провайдера **Gmail**, укажите полный адрес `name@gmail.com` и этот пароль приложения.

Параметры подставляются автоматически:

- IMAP: `imap.gmail.com`, порт `993`, SSL;
- SMTP: `smtp.gmail.com`, порт `465`, SSL;
- логин: полный адрес Gmail.

Для личных Google-аккаунтов IMAP включён постоянно с 2025 года. Для этого способа требуется двухэтапная аутентификация и пароль приложения; Google Workspace может запрещать такие пароли политикой организации. В таком случае понадобится OAuth-подключение, а не IMAP-пароль.

Официальные инструкции: <https://support.google.com/mail/answer/7126229> и <https://support.google.com/accounts/answer/2461835>.

## 5. Синхронизация

В кабинете можно обновить один ящик или нажать **Синхронизировать все**. Для автоматического запуска используется команда:

```powershell
.\venv\Scripts\python.exe manage.py sync_mailboxes
```

Для одного ящика:

```powershell
.\venv\Scripts\python.exe manage.py sync_mailboxes --mailbox 12 --limit 200
```

В production запускайте общую команду каждые 5 минут через Windows Task Scheduler, cron или системный планировщик сервера. Одновременно должен работать только один экземпляр команды.

## 6. Если подключение не работает

- Используйте пароль приложения, а не основной пароль аккаунта.
- Проверьте полный email в качестве логина.
- Убедитесь, что разрешена работа почтовых программ/IMAP.
- Проверьте доступ сервера к исходящему порту `993` и SMTP-порту `465`.
- После смены пароля аккаунта или отзыва пароля приложения создайте новый пароль и переподключите ящик.
- Текст последней IMAP-ошибки отображается прямо в карточке ящика.
